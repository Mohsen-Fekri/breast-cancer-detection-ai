Breast Cancer Detection AI

A deep learning classifier that flags breast ultrasound scans for review and shows, with a Grad-CAM heatmap, which region drove each prediction. The model runs entirely in your browser with ONNX Runtime, so any image you try never leaves your computer.

Training setup

BackboneEfficientNet-B0, ImageNet weights, last 3 blocks fine-tuned
Data546 training images, official MedMNIST splits
Training10 epochs, weighted BCE loss, flip + ±10° rotation, seed 2026

How it works

  1. Data. BreastMNIST is a 224×224 version of the BUSI breast ultrasound dataset, with official train, validation and test splits. Malignant is the positive class.
  2. Model. An ImageNet EfficientNet-B0 is fine-tuned on the 546 training images. Only the last three blocks are trained, which keeps training practical on a laptop CPU and limits overfitting on a small dataset.
  3. Explainability. Browsers can't run backpropagation, so Grad-CAM is computed differently here. The network ends in average pooling and a single linear layer, so the Grad-CAM weights equal that layer's weights. The heatmap is computed in the forward pass and exported with the model.
  4. Deployment. The model is exported to ONNX and runs client-side with ONNX Runtime Web. The repo also includes a Streamlit app, a Dockerfile, unit tests and CI.

Limitations

  • The dataset is small (780 images) and comes from a single hospital, so these scores may not hold on scans from other machines or clinics.
  • The model misses about 1 in 7 malignant scans at the default threshold. Lowering the threshold catches more, at the cost of more false alarms.
  • The score is not calibrated, so treat it as a ranking signal rather than a probability.
  • On clearly benign scans the heatmap can be empty, because nothing in the image pushes the score toward malignant.
